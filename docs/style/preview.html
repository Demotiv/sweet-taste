Принципы
Чтобы приложение не мешало работе
  • Один акцентный цвет — только для главного действия.
  • Никаких анимаций размера текста: только мягкое изменение фона.
  • Данные — главное: таблицы читаются с расстояния вытянутой руки.
  • Тени лёгкие, границы тонкие, скругления 9–14 px.
  • Тёмный шоколадный текст вместо чёрного — меньше контраста, меньше усталости.
Это макет для утверждения направления. Если понравится — перенесу токены в Avalonia (шрифты Lora и Manrope с кириллицей, встроенные в приложение).
