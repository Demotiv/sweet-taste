# Sweet Taste 0.1.0-alpha.4

Тестовая сборка для проверки автообновления.

## Что нового

- Функциональных изменений нет: версия нужна, чтобы проверить обновление с `0.1.0-alpha.3`.
- После установки внизу бокового меню должна отображаться версия `0.1.0-alpha.4`.

## Как проверить

1. Установите `0.1.0-alpha.3` из GitHub Releases.
2. Запустите приложение. Через несколько секунд должен появиться баннер
   «Доступна версия 0.1.0-alpha.4».
3. Нажмите «Обновить». Приложение скачает ZIP, проверит SHA-256, закроется,
   заменит файлы и запустится снова.
4. Проверьте версию внизу меню, данные и заказы.
5. Рядом со старой папкой появится `...-old-0.1.0-alpha.3-<дата>`.
6. В `%APPDATA%\SweetTaste\backups` появится копия базы `pre-update-<дата>.db`.

Если что-то пойдёт не так, журнал: `%LOCALAPPDATA%\SweetTaste\update.log`.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, бэкапы — в `backups\`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Миграции базы односторонние.
