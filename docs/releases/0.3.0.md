# Sweet Taste 0.3.0

Минорное обновление: кликабельные строки списков, закрытие просмотровых окон
по фону и обновлённая сборка на GitHub Actions.

## Что нового

- На странице «Ингредиенты» карточка ингредиента открывается нажатием на любую часть
  строки, а не только на цену. Кнопки цены, изменения и удаления работают как раньше.
- На странице «Заказы» детали заказа открываются нажатием на любую часть строки.
  Кнопки в строке работают как раньше.
- Просмотровые окна закрываются кликом по затемнённому фону: детали заказа,
  карточка клиента, превью рецепта, история ингредиента, список упаковки.
- Формы и подтверждения по фону не закрываются — только кнопкой или Esc,
  чтобы не терять введённые данные.
- 115 тестов логики.

Схема базы не менялась (версия 15), данные и настройки сохраняются как есть.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль, без синхронизации и облака.
- Миграции базы односторонние.
