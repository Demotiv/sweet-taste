# Sweet Taste 0.1.0-alpha.2

Вторая альфа-версия Windows-приложения для кондитера.
Данные из `0.1.0-alpha.1` совместимы: база и бэкапы лежат отдельно от программы.

## Что нового с 0.1.0-alpha.1

- «Рецепты» и «Упаковки» собраны в раскрывающиеся группы по категориям, как ингредиенты.
- В «Рецептах» фильтр по категории заменён группами; кнопка «Категории» убрана.
- Категории рецептов переименовываются и удаляются прямо из заголовка группы.
- Просмотр рецепта по нажатию на строку: фото, состав, расчёт и пошаговая технология.
- Из карточки рецепта можно сразу перейти к редактированию.
- Курсор-рука на всём, что нажимается: кнопки, вкладки, календарь и списки.
- Напоминание о выдачах обновляется при изменении заказов и исчезает после выдачи.
- Статус заказа меняется из деталей: Новый, Готовится, Готов, Выдан, Отменён.
- Заказ можно вернуть из архива в текущие, если статус нажали случайно.
- «Опасная зона» в настройках: один блок «Удаление заказов» с выбором
  «Очистить архив» или «Удалить все заказы».
- Из бокового меню убрана кнопка «Профиль» — переход остался по карточке внизу.
- «Без категории» защищена от создания и переименования.
- 104 теста логики.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd` — появится ярлык на рабочем столе.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.
Они не входят в папку приложения, поэтому обновление их не затрагивает.

## Обновление

1. Закройте приложение.
2. Перетащите новый ZIP на `Update.cmd`.
3. Скрипт сохранит текущую версию в папке `...-old-<версия>-<дата>` и запустит новую.

Перед обновлением сделайте бэкап: «Настройки» → «Создать резервную копию».

## Проверка файла

`SHA-256` лежит рядом с архивом в файле `*.zip.sha256`.

## Ограничения

- Windows 10/11, 64-bit.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль, без синхронизации и облака.
- Миграции базы односторонние.
