# Sweet Taste 0.1.0-alpha.3

Третья альфа-версия Windows-приложения для кондитера.
Главное изменение — автоматическая проверка обновлений на GitHub.

## Что нового с 0.1.0-alpha.2

- При запуске приложение проверяет GitHub Releases и показывает баннер,
  если доступна новая версия.
- Обновление скачивается по кнопке «Обновить», хеш SHA-256 проверяется автоматически.
- После скачивания приложение закрывается, заменяет файлы и запускается снова.
- Старая папка сохраняется рядом как `<имя>-old-<версия>-<дата>`.
- Перед заменой автоматически создаётся копия базы в `backups\`.
- Данные в `%APPDATA%\SweetTaste` не меняются.
- Если интернета нет, приложение работает как обычно — проверка просто пропускается.
- Журнал обновления: `%LOCALAPPDATA%\SweetTaste\update.log`.
- 115 тестов логики.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd` — появится ярлык на рабочем столе.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически: баннер «Доступна версия …» → «Обновить».
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.

Перед обновлением можно дополнительно сделать бэкап: «Настройки» → «Создать резервную копию».

## Проверка файла

`SHA-256` лежит рядом с архивом в файле `*.zip.sha256`.
При автоматическом обновлении приложение проверяет его само.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль, без синхронизации и облака.
- Миграции базы односторонние.
