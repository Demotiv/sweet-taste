# Sweet Taste 0.7.0

Новая настройка синхронизации: автовыгрузку в облако при закрытии приложения
можно отключить. Полезно, когда данные неполные или неточные и отправлять их
в облако не нужно.

## Что нового

- **Переключатель «Выгружать данные в облако при закрытии приложения»**
  в карточке «Синхронизация» на странице «Настройки». По умолчанию включён,
  поведение не меняется.
- **Отключается только автовыгрузка.** Кнопки «Выгрузить в облако»,
  «Загрузить из облака» и «История облака» работают всегда — ручная выгрузка
  остаётся доступной при любом положении переключателя.
- **Настройка своя на каждом компьютере.** Флаг хранится в локальной базе
  и в облако не попадает: на ноутбуке можно выгрузку выключить, на домашнем
  компьютере оставить включённой.
- **Причина пропуска видна в журнале.** Если выгрузка отключена, при закрытии
  в `%LOCALAPPDATA%\SweetTaste\sync.log` появляется строка
  «выгрузка при закрытии отключена в настройках».
- **Сообщения в карточке стали точнее.** После входа и после восстановления
  версии из истории больше не обещается выгрузка при закрытии — состояние
  показывает сам переключатель.
- 211 тестов логики.

## Схема базы

Версия схемы не менялась (16), миграций нет. Новая настройка — обычная строка
в таблице `app_settings`, она создаётся при первом сохранении.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `tools\CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `tools\Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль. Синхронизация — полный снимок: облако повторяет
  последнюю выгрузку, одновременная работа на двух компьютерах не поддерживается.
- Работы с телефона пока нет.
- Миграции базы односторонние.
