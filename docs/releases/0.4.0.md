# Sweet Taste 0.4.0

Минорное обновление: вход в аккаунт и выгрузка данных в облако при закрытии
приложения. Локальная база остаётся основным источником данных.

## Что нового

- В «Настройках» появилась карточка «Синхронизация»: вход по email и паролю
  в аккаунт Supabase.
- После входа данные при закрытии приложения выгружаются в облако — полный
  снимок ингредиентов, закупок, рецептов, клиентов и заказов.
- Сессия входа хранится зашифрованной (DPAPI) рядом с базой и восстанавливается
  при следующем запуске.
- Приложение по-прежнему работает без сети и без входа: локальная база —
  основной источник данных, облако — копия.
- Регистрации в приложении нет: аккаунт создаётся вручную в панели Supabase.
- 115 тестов логики.

Схема базы не менялась (версия 15), данные и настройки сохраняются как есть.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль. Синхронизация — только выгрузка в облако при закрытии;
  загрузки из облака и работы с телефона пока нет.
- Миграции базы односторонние.
