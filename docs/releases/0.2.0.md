# Sweet Taste 0.2.0

Первая стабильная версия с ручной проверкой обновлений.

## Что нового

- Версия без суффикса `alpha`.
- В настройках появилась кнопка «Проверить обновления».
- Проверка использует Atom-ленту GitHub Releases и не расходует лимит GitHub API.
  Если лента недоступна, приложение переходит на обычный API.
- Если доступна новая версия, сверху появляется баннер с кнопкой «Обновить».
- На главной странице репозитория есть прямая ссылка на последний ZIP.
- Автоматическая проверка при запуске сохранена.
- 115 тестов логики.

## Скачать

Постоянная ссылка на последнюю версию:

https://github.com/Demotiv/sweet-taste/releases/latest/download/SweetTaste-win-x64.zip

SHA-256 лежит рядом: `SweetTaste-win-x64.zip.sha256`.
Архив с номером версии тоже сохраняется в релизе.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль, без синхронизации и облака.
- Миграции базы односторонние.
