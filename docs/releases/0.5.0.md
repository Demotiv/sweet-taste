# Sweet Taste 0.5.0

Минорное обновление: данные теперь можно не только выгружать в облако,
но и загружать обратно на компьютер. Это нужно, чтобы перенести базу
на второй компьютер или вернуть данные после переустановки.

## Что нового

- В карточке «Синхронизация» после входа появились две кнопки:
  «Выгрузить в облако» и «Загрузить из облака».
- «Выгрузить в облако» отправляет полный снимок данных сразу, не дожидаясь
  закрытия приложения.
- «Загрузить из облака» заменяет данные на этом компьютере данными из облака.
  Перед заменой создаётся резервная копия текущей базы, после замены
  приложение предлагает перезапуститься.
- Загрузка идёт через подтверждение: случайно нажать и потерять данные нельзя.
- Настройки устройства и профиль кондитера при загрузке не меняются —
  они остаются локальными.
- Если данные в облаке сохранены более новой версией приложения, загрузка
  откажется их применять и попросит обновить программу.
- 183 теста логики.

Схема базы не менялась (версия 15), данные и настройки сохраняются как есть.

## Как перенести данные на второй компьютер

1. На первом компьютере: «Настройки» → «Выгрузить в облако».
2. На втором: войти в тот же аккаунт → «Загрузить из облака» → перезапустить.

Важно: при закрытии приложение выгружает свою базу в облако. Поэтому на новом
компьютере сначала загрузите данные из облака и только потом работайте —
иначе пустая база затрёт облачную копию.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль. Синхронизация — полный снимок: облако повторяет
  последнюю выгрузку, одновременная работа на двух компьютерах не поддерживается.
- Работы с телефона пока нет.
- Миграции базы односторонние.
