# Sweet Taste 0.6.0

Минорное обновление: облако перестало быть «одной копией без истории».
Перед каждой выгрузкой прежнее состояние сохраняется в архив, любую из
последних десяти версий можно вернуть на компьютер. В карточке синхронизации
появились две даты — когда менялись данные здесь и когда обновлялось облако.

## Что нового

- **История облака.** Перед каждой выгрузкой приложение сохраняет текущее
  состояние облака в архив. Хранятся последние 10 версий.
- **Кнопка «История облака»** в карточке «Синхронизация»: список версий
  с датой, числом строк и версией схемы. Выбранную версию можно вернуть
  на этот компьютер.
- **Восстановление версии** идёт через резервную копию текущей базы,
  после замены приложение предлагает перезапуститься. При закрытии
  восстановленные данные уходят в облако.
- **Подтверждение выгрузки.** «Выгрузить в облако» сначала показывает,
  что лежит в облаке и что уйдёт с этой машины, — и только потом выгружает.
- **Две даты в карточке:** «На этом компьютере» — когда локальные данные
  последний раз менялись, «В облаке» — когда обновлялось облако.
  Если локальное новее, горит «Есть невыгруженные изменения.».
- 208 тестов логики.

## Схема базы

Версия схемы 16: добавлена отметка последнего изменения данных, её ставят
триггеры SQLite. Миграция выполняется автоматически при первом запуске,
данные и настройки сохраняются как есть. Версия схемы снапшота в облаке
не менялась (15), поэтому обмен данными с версией 0.5.0 остаётся совместимым.

## Установка

1. Распакуйте ZIP целиком, например в `C:\SweetTaste`.
2. Запустите `SweetTaste.exe`. .NET устанавливать не нужно.
3. При желании запустите `CreateShortcut.cmd`.

Данные: `%APPDATA%\SweetTaste\sweet-taste.db`, резервные копии — в `backups\`.

## Обновление

- Автоматически из баннера.
- Вручную: закройте приложение и перетащите новый ZIP на `Update.cmd`.
- Проверка вручную: «Настройки» → «Проверить обновления».

Перед заменой файлов создаётся копия базы в `backups\`.
Старая папка сохраняется как `<имя>-old-<версия>-<дата>`.

## Ограничения

- Windows 10/11, 64-bit.
- Для проверки обновлений нужен доступ к GitHub.
- Файл не подписан: SmartScreen может попросить «Подробнее» → «Выполнить в любом случае».
- Один локальный профиль. Синхронизация — полный снимок: облако повторяет
  последнюю выгрузку, одновременная работа на двух компьютерах не поддерживается.
- Работы с телефона пока нет.
- Миграции базы односторонние.
