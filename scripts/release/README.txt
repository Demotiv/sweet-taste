# Sweet Taste — альфа-сборка

## Что это

Полноценное Windows-приложение для кондитера: ингредиенты, закупки, рецепты,
клиенты, заказы, упаковка и отчёты. Работает без интернета.

Версия — в левом нижнем углу приложения и в файле `version.json`.

## Как запустить

1. Распакуйте архив целиком в удобную папку, например `C:\SweetTaste`.
   Не запускайте программу прямо из ZIP — ей нужны соседние файлы.
2. Запустите `SweetTaste.exe`.
3. Установка не нужна: внутри уже есть всё необходимое, включая .NET 8.
4. Ярлык на рабочий стол: запустите `CreateShortcut.cmd`
   (или закрепите `SweetTaste.exe` на панели задач).

При первом запуске база создаётся автоматически.

## Предупреждение Windows

Файл не подписан сертификатом, поэтому SmartScreen может показать
«Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».
Это нормально для альфа-версии: приложение не скачивает ничего из интернета.

## Где лежат данные

```
%APPDATA%\SweetTaste\sweet-taste.db
%APPDATA%\SweetTaste\backups\
```

Данные хранятся отдельно от папки программы. Поэтому обновление,
переименование или перенос папки приложения их не затрагивают.

Сделать резервную копию: «Настройки» → «Создать резервную копию».
Полная выгрузка для переноса на другой ПК: «Профиль» → «Перенос данных».

## Как обновить

1. Закройте Sweet Taste (все окна).
2. Скачайте новый ZIP.
3. Перетащите ZIP мышью на файл `Update.cmd` в папке программы
   (или запустите `Update.cmd` и укажите путь к ZIP).
4. Скрипт проверит, что приложение закрыто, сохранит текущую версию рядом
   в папке `<имя>-old-<версия>-<дата>` и запустит новую.

Если что-то пошло не так, верните старую версию:

1. Закройте приложение.
2. Удалите (или переименуйте) новую папку программы.
3. Переименуйте папку `<имя>-old-<версия>-<дата>` обратно в исходное имя.

Перед обновлением всё равно сделайте бэкап базы: миграции базы
односторонние, откат приложения без отката базы может не сработать.

## Проверка ZIP

Рядом с архивом лежит файл `*.zip.sha256`. Проверить в PowerShell:

```powershell
Get-FileHash .\SweetTaste-...-win-x64.zip -Algorithm SHA256
```

Хеш должен совпасть с содержимым `.sha256`.

## Состав папки

```
SweetTaste.exe        приложение
version.json          версия, схема базы и дата сборки
Update.cmd            обновление из нового ZIP
Update.ps1            логика обновления (вызывается из Update.cmd)
CreateShortcut.cmd    ярлык на рабочем столе
README.txt            этот файл
*.dll, *.json, ...    компоненты приложения — не удаляйте их
```

## Ограничения альфы

- Только Windows 10/11, 64-bit.
- Нет автообновления «в один клик» — обновление через `Update.cmd`.
- Подписи сертификатом нет, поэтому возможно предупреждение SmartScreen.
- Один профиль кондитера и локальная база без синхронизации.

Пожелания и найденные ошибки лучше записывать сразу: что делали,
что ожидали и что произошло.
