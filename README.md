# Sweet Taste

Офлайн-приложение для кондитера: ингредиенты, закупки, рецепты, заказы, упаковка и отчёты.
Windows · .NET 8 · Avalonia UI · SQLite.

Текущий этап и решения: см. [PLAN.md](PLAN.md).

## Что уже работает

### Ингредиенты и закупки

- Справочник ингредиентов: название, бренд, единица (г / мл / шт).
- Категории ингредиентов: создаются из формы, список — раскрывающиеся группы по категориям.
- Удаление категории ингредиентов: товары переходят в «Без категории», ничего не теряется.
- Категории рецептов: создаются из формы, удаление — из заголовка группы; рецепты переходят в «Без категории».
- В выпадающих списках закупки и состава рецепта ингредиенты сгруппированы по категориям.
- Удаление ингредиента и рецепта — в корзину, с подтверждением.
- Корзина: отдельные разделы «Ингредиенты» и «Рецепты»; восстановление и окончательное удаление.
- Мягкое удаление: закупки и состав рецептов сохраняются, пока позиция в корзине.
- Журнал закупок: дата, магазин, объём, сумма.
- Редактирование закупок: дата, магазин, объём, сумма и заметка (ингредиент фиксирован).
- Средняя цена по всем закупкам (взвешенная) и цена за единицу.
- Подсказка при наведении на цену, полная история — по клику.
- Добавление, изменение, удаление ингредиентов и закупок с подтверждением.
- Поиск по названию и бренду.
- Цифры месяца: потрачено, количество закупок, крупная закупка.

### Рецепты

- Книга рецептов: состав, выход (шт / кг / г, может быть дробным), категории и наценка.
- Рецепты собраны в раскрывающиеся группы по категориям: нажатие на категорию показывает её рецепты.
- Нажатие в любом месте строки рецепта (кроме кнопок изменения и удаления) открывает карточку:
  фото, выход, наценка, себестоимость, цена, состав и технология по шагам.
- Категорию можно переименовать или удалить прямо из заголовка группы.
- Технология приготовления и фото рецепта; фото видно в книге.
- Пересчёт состава под другое количество прямо в форме рецепта.
- Категории рецептов и ингредиентов можно переименовывать и удалять.
- Себестоимость партии, себестоимость единицы и цена с наценкой.
- Пересчёт по текущим средним ценам ингредиентов — цена обновляется сама.
- Категории создаются прямо из формы рецепта; поиск по книге.
- Живой предпросмотр расчёта при редактировании состава.
- Ингредиент, который используется в рецепте, нельзя удалить из справочника.

### Заказы и упаковка

- Заказы: клиент, телефон, дата выдачи, состав, статусы и архив.
- Клиенты: отдельная база, номер при первом заказе, телефон нормализуется (8 и +7 — один номер).
- Автозаполнение имени, фамилии и телефона по телефону или фамилии прямо в форме заказа.
- Вкладка «Клиенты» в заказах: карточка клиента, история и повтор последнего заказа.
- Из карточки клиента можно открыть любой его заказ; клиента можно удалить — заказы останутся в истории.
- Количество в заказе — в единицах рецепта: только целые штуки или вес (1,5 кг);
  состав и список покупок масштабируются пропорционально.
- Список покупок под заказ по текущим средним ценам: галочки «куплено», копирование и печать.
- Цена и себестоимость фиксируются в заказе на момент оформления.
- Предоплата, остаток к оплате и отметка «оплачен».
- Предоплата по умолчанию — 50% суммы, её можно изменить.
- Итоговая сумма округляется вверх до целого рубля.
- Скидка на заказ; итог пересчитывается, история цен не меняется.
- При запуске — напоминание о заказах на сегодня и завтра; оно обновляется при изменениях и исчезает после выдачи.
- В деталях заказа статус можно переключить на любой, включая возврат из архива в текущие.
- Упаковка: отдельный справочник в «Ингредиентах» — категории коробок, размеры и закупочные цены.
- Упаковки собраны в раскрывающиеся группы по категориям с количеством и удалением категории.
- В деталях заказа выбираются коробки с количеством; итог пересчитывается и сохраняется сразу.
- К цене упаковки применяется средневзвешенная наценка блюд заказа.

### Отчёты

- Выручка, прибыль, число заказов, средний чек и затраты на закупки за период.
- Период: неделя, месяц, год или произвольный диапазон; учёт по дате выдачи.
- Вкладка «Клиенты»: заказы, выручка, средний чек и последний заказ каждого клиента.
- Диаграммы: топ рецептов по количеству, выручка по дням и «кто заказывает чаще».
- Экспорт: CSV для Excel и HTML для печати или сохранения в PDF.
- Печатный отчёт — строгая серая таблица, удобная для документов.

### Настройки

- Тема: светлая, тёмная или как в системе; переключается сразу, без перезапуска.
- Резервные копии: срок хранения, ручной бэкап с меткой времени, открыть папку.
- Восстановление базы из файла с автоматическим бэкапом текущей версии.
- Масштаб интерфейса 90–125%.
- Значения по умолчанию для новых рецептов: наценка и единица выхода.
- Опасная зона «Удаление заказов»: очистка архива или всех заказов; отчёты строятся по заказам, поэтому очищаются вместе с ними.

### Профиль

- Название кондитерской, имя, Instagram, Telegram и сайт.
- Логотип или фото: сжимается, хранится в базе и попадает в бэкап.
- Название и имя показываются в боковом меню, фото — в карточке профиля.
- Все ингредиенты, рецепты, заказы, закупки и упаковка привязаны к профилю.
- Перенос данных: полная копия базы в выбранную папку и инструкция по восстановлению на другом ПК.

Общее:

- SQLite, миграции и ежедневные резервные копии.
- Единый стиль: скругления, выравнивание полей, аккуратные поповеры.
- Курсор-рука на всём, что нажимается: кнопки, вкладки, календарь, списки.

## Альфа-сборка

Готовый архив для Windows: `dist/SweetTaste-0.1.0-alpha.2-win-x64.zip` (рядом `.sha256`).
Установка не нужна, .NET 8 ставить не нужно — распакуйте и запустите `SweetTaste.exe`.

- Ярлык на рабочий стол: `CreateShortcut.cmd` в папке программы.
- Обновление: закройте приложение и перетащите новый ZIP на `Update.cmd`.
  Старая версия сохранится рядом (`...-old-<версия>-<дата>`) для отката.
- Данные — в `%APPDATA%\SweetTaste`; обновление папки приложения их не затрагивает.
- Версия — в левом нижнем углу приложения и в `version.json`.
- Неподписанный `.exe` может вызвать предупреждение SmartScreen:
  «Подробнее» → «Выполнить в любом случае».
- Перед обновлением делайте бэкап: «Настройки» → «Создать резервную копию».

Собрать релиз заново:

```powershell
pwsh -File scripts/release.ps1
```

Скрипт прогоняет тесты, публикует self-contained `win-x64`, добавляет README,
`Update.cmd`, `CreateShortcut.cmd`, `version.json`, упаковывает ZIP и считает SHA-256.
Версия задаётся в `src/SweetTaste.Desktop/SweetTaste.Desktop.csproj` (`<Version>`).

## Релизы на GitHub

- При каждом push в `main` и в pull request GitHub Actions собирает проект и прогоняет тесты.
- Релиз создаётся тегом версии. Например, для `0.1.0-alpha.2`:

```powershell
git tag v0.1.0-alpha.2
git push origin v0.1.0-alpha.2
```

GitHub Actions соберёт self-contained ZIP, посчитает SHA-256 и опубликует релиз
с архивом и заметками из `docs/releases/<версия>.md`. Alpha-версии помечаются как pre-release.

## Запуск для разработки

Нужен .NET 8 SDK.

```powershell
dotnet build
dotnet run --project src/SweetTaste.Desktop
```

Тесты логики:

```powershell
dotnet test
```

## Где лежат данные

`%APPDATA%\SweetTaste\sweet-taste.db`
Резервные копии: `%APPDATA%\SweetTaste\backups\` (хранятся 14 дней).

Для разработки путь к базе можно переопределить:

```powershell
$env:SWEET_TASTE_DB = "D:\temp\sweet-test.db"
```

## Структура

```
src/SweetTaste.Core        домен, SQLite, сервисы (без UI)
src/SweetTaste.Desktop     Avalonia UI (MVVM), иконка и шрифты
tests/SweetTaste.Core.Tests
scripts/release.ps1        сборка альфа-релиза
scripts/release/           README и скрипты обновления внутри ZIP
docs/style/preview.html    утверждённый макет стиля
dist/                      готовые ZIP и SHA-256
```
